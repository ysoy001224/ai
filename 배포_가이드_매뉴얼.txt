==============================================================================
 [서용엔지니어링] 누수음 지능형 진단 클라우드 원클릭 무료 배포 가이드 (3분 완성)
==============================================================================

본 폴더(서용_누수음_클라우드_배포패키지)는 회사 컴퓨터를 24시간 켜둘 필요 없이,
클라우드 무료 호스팅 공간에 3분 만에 올려 스마트폰 전용 HTTPS 주소를 얻을 수 있도록 
모든 AI 모델과 엔진을 단독 완결형(Self-Contained)으로 패키징한 결과물입니다.


■ 가장 추천하는 무료 배포 방법: Hugging Face Spaces (완전 무료, 상시 가동, HTTPS 기본)
------------------------------------------------------------------------------
 1. https://huggingface.co 회원가입 및 로그인 (무료)
 2. 우측 상단 프로필 클릭 -> [New Space] 선택
 3. Space 설정:
    - Space name: seoyong-leak-ai (원하는 영문 이름)
    - License: MIT 또는 Apache 2.0
    - Space SDK: [Docker] 선택  <-- 중요! (Blank Docker 선택)
    - Space Hardware: Free (CPU basic, 2 vCPU, 16GB RAM) - 무료 선택
    - [Create Space] 클릭
 4. 파일 업로드:
    - 생성된 Space 화면 상단의 [Files] 탭 클릭 -> [Add file] -> [Upload files] 선택
    - 본 폴더(서용_누수음_클라우드_배포패키지) 안의 모든 파일과 models 폴더를 드래그하여 업로드:
      * app.py
      * requirements.txt
      * Dockerfile
      * pipe_profiler_model.pkl
      * models/ 폴더 전체 (xgb_pure_acoustic.pkl, xgb_pipe_physical.pkl)
    - 하단 [Commit changes to main] 초록색 버튼 클릭!
 5. 배포 완료 (약 2~3분 소요):
    - 자동으로 Docker 빌드가 진행된 후 "Running" 상태로 변경됩니다.
    - 상단의 [...] 메뉴 -> [Embed this Space] 또는 [Direct URL]을 클릭하면 
      스마트폰에서 접속할 수 있는 고유 보안 주소가 나타납니다.
      예: https://[사용자명]-seoyoung-leak-ai.hf.space


■ 현장 스마트폰에서 앱처럼 사용하는 방법 (PWA 홈 화면 추가)
------------------------------------------------------------------------------
 1. 현장 탐사원에게 위 클라우드 주소(https://...hf.space)를 카카오톡으로 전송합니다.
 2. 스마트폰(안드로이드 크롬 또는 아이폰 사파리)으로 주소를 엽니다.
 3. 브라우저 메뉴(점 3개 또는 공유 버튼) -> [홈 화면에 추가] 또는 [앱 설치]를 터치합니다.
 4. 스마트폰 바탕화면에 "서용 누수진단" 전용 앱 아이콘이 생성됩니다.
 5. 현장에서는 앱 아이콘을 터치해 들어가서:
    - [음원 선택] -> 청음기에서 다운로드된 WAV 선택
    - [관종/관경/심도] 입력 -> [🚀 현장 즉시 AI 정밀 진단] 터치
    - 1초 만에 듀얼 확률 게이지, 스펙트로그램, 분출 형태가 출력됩니다.


■ 현장 굴착 실증 피드백 기록 기능 (TRL 6 도약용)
------------------------------------------------------------------------------
 - 모바일 결과 화면 하단에 [🎯 실제 누수 맞음] / [❌ 꽝 (정상이었음)] 버튼이 탑재되어 있습니다.
 - 실제로 땅을 파본 뒤 이 버튼을 누르면, 서버의 'field_validation_log.csv' 파일에 
   현장 굴착 실증 대조 결과가 시간별로 자동 누적됩니다.
 - 이 누적 로그가 향후 지자체 납품 및 신기술(NET) 인증의 결정적 증거 자료가 됩니다.
